CIS341 Portfolio Website - Designed Version

Files:
- index.html: Homepage, with NO personal photo.
- contact.html: Contact form page.
- style.css: Shared dark navy / blue / purple visual design.

Before submitting:
1. Replace YOUR FULL NAME with your full name.
2. Replace YOUR_SID with your student ID.
3. Replace YOUR_UNIVERSITY_EMAIL@cit.just.edu.jo with your actual university email everywhere in both HTML files.
4. Confirm the major and all content are accurate.
5. Open index.html in a browser and test the Home and Contact Me links.
6. Test the contact form with missing fields and with valid values.

Important: the contact form displays a success message but does not transmit/store submissions because there is no server-side backend. This matches the assignment's JavaScript alert requirement.
